# Library Management System

A complete, secure, responsive, production-quality Library Management System built with PHP 8+, MySQL, HTML5, CSS3, and JavaScript.

## Features

- **Role-Based Access Control** - Administrator, Librarian, and Member roles
- **Book Management** - Full CRUD with cover image upload, copies management
- **Member Management** - Registration, profile management, borrowing history
- **Loan Management** - Issue, return, renew books with automatic due date calculation
- **Reservation System** - Members can reserve unavailable books
- **Fine Management** - Automatic fine calculation, payment recording, waiving
- **Reports** - 16+ report types with CSV export and print
- **Notifications** - Internal notification system for all users
- **Dashboard** - Interactive charts and statistics
- **Audit Logs** - Complete audit trail of all actions
- **System Settings** - Configurable library settings
- **Secure** - PDO prepared statements, CSRF protection, XSS prevention, password hashing

## Requirements

- PHP 8.0 or higher
- MySQL 5.7 or higher
- Apache or Nginx web server
- XAMPP/WAMP/LAMP recommended
